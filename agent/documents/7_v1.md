# Engineering tool documentation

The following tools are available to engineers and agents working on the TRS analysis. All three are published on PyPI and launched via `uvx` (no installation required); the two MCP servers are wired into `agent/.mcp.json`.

| Tool name       | Type          | Description | Docs (human) | Docs (agents, `llms.txt`) |
|-----------------|---------------|-------------|--------------|---------------------------|
| `folios`        | MCP server    | Serves the design-practice documents in `agent/documents/` (this folder) over MCP. Used by agents to retrieve approved engineering practice as the source of truth before acting. | <https://pypi.org/project/folios/> | TBD |
| `mock-gkn-hpc`  | MCP server    | Mocks GKN's HPC for Ansys/FEA submissions. Exposes `submit_ansys_run`, `list_jobs`, `status`, `delete_results` and templated `ansys://{job_id}/log` and `ansys://{job_id}/results` resources. Mirrors the `qansys` CLI flag surface. | <https://github.com/alex-pradas/mock-gkn-hpc> | TBD |
| `ductile-loads` | Python module | Processes OEM load deliveries into ANSYS APDL `.inp` files for the limit-load envelope. Run via `uv` from the CLI or imported as a library. | <https://alex-pradas.github.io/ductile-loads/> | <https://alex-pradas.github.io/ductile-loads/llms-full.txt> |
